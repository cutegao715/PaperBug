# 前端功能连接记录

日期：2026-10-28。本轮只连接既有页面、控件和详情弹窗，不修改产品原型、页面 HTML、CSS、导航结构或视觉资源。

## 发现的问题与处理

| 原问题 | 当前连接方式 |
| --- | --- |
| 交付绑定和研究复用要求手填文件路径 | 从当前研究的草稿、显式导入资料和导出文件中选择；复用来源稿件同样使用选择列表 |
| 局部任务只能通过 API 创建 | 既有“建立交付记录”按钮打开原详情弹窗，设置完整／局部范围、本次交付物和参考资料 |
| 多份同类记录时，对话和生成文件归属不明确 | 明确选择 case_id，传入现有 workflow_options；局部范围进入模型契约，结束时只登记到选中的记录 |
| 后台刷新覆盖尚未保存的决定、关注配置 | 未提交输入按研究空间和记录分别保留；请求加版本标记，旧响应不覆盖新研究空间 |
| 主界面的投稿管理没有连到领域状态 | 在现有流程记录中打开原弹窗，登记实际投稿、查看来源历史、更新编辑决定、识别用户提供的邮件、关联当前 P3 记录 |
| 返修轮次和拒稿改投缺少关联 | 保存实际投稿日期，累计返修轮次；拒稿后可进入 P2 重新匹配，并登记关联原投稿的新记录，保留原拒稿历史 |
| 已有投稿包、PPTX、讲稿无法从当前记录下载 | 现有文件弹窗列出可下载文件；可生成本地投稿 ZIP 和基于已保存演示结构的 PPTX、HTML、讲稿及清单 |
| 正式确认按钮可在缺文件或存在错误时点击 | 显示待处理原因，条件未满足时禁用；后端仍独立验证正式版本与 ERROR 门禁 |
| 历史已绑定文件变化后，无法取得当时版本 | 交付记录下载固定的 workflow_versions 快照；下载不偷偷替换成当前文件 |
| 主稿选择没有同步对话焦点，刷新后又选回第一份 | 选择稿件同步 conversation/focus，刷新优先显示已记录的稿件；运行期间阻止切换和编辑 |
| 请求失败仍清空聊天输入 | 工作区、首页和快捷输入仅在请求接受后清空 |
| 调整生命周期后，历史流程可能导致整个研究空间加载失败 | 保留原历史，返回提示并允许重新选择；不将旧生命周期记录自动投入新运行 |
| 新技能只能从高级设置查看 | 在现有流程说明处查看适用方法，支持入口与内部资源分页读取 |

## 功能边界

所有新增业务交互复用既有 `detailModal`，保持页面结构和样式。具体方法仍由 Agent 按请求选择；选择 Workflow 不会强制执行每个 Skill。API 仅返回当前研究已知的文件和投稿记录，跨研究复用需要显式选择来源。

对话在多个活动记录之间不会任意选择：可以指定记录；存在歧义时保留待发文字并请求选择。已暂停记录可查看历史，但不能启动新运行。完成记录需要重开修订后才能继续登记产物。

稿件选择器、交付选择器和下载是不同语义：稿件选择更新对话焦点；绑定固定文件版本；下载交付记录时取得所绑定版本。改变已关联投稿的状态也会改变 P3 正式交付指纹，要求重新核对正式版本。

“登记投稿／更新决定／登记改投”只保存用户已经实际执行或收到的信息，不执行任何对外投稿。用户提供的邮件先解析展示，再明确确认应用；缺少稿件编号或存在歧义时不自动更新。真实邮箱账户自动收信仍需已授权的账户适配器，不能由本地邮件内容输入代替。

答辩生成入口接收已经保存的演示结构，未形成结构时可以通过原对话入口请求助手基于真实论文准备。PPTX、HTML 预览和讲稿均可下载；来源与文件检查不等于科学有效性或 Office 版式认证，原 SVG 图表仍按配套资源规则处理。

## 接口

- `GET /api/projects/{id}/file-options`：当前研究可选择的文件与可否绑定为输出。
- `GET /api/projects/{id}/files/download`：仅下载本研究文件列表中实际存在的文件。
- `GET /api/projects/{id}/workflow-cases/{case}/file`：下载绑定的不可变交付版本。
- `GET/POST /api/projects/{id}/submissions`：研究空间内的投稿记录。
- `POST /api/projects/{id}/submissions/{submission}/status`：带来源和旧状态检查的决定更新。
- `POST /api/projects/{id}/submission-email`：邮件内容预览／明确应用。
- `POST /api/projects/{id}/deliveries/submission-package`：生成已有稿件的本地投稿材料包。
- `POST /api/projects/{id}/deliveries/presentation`：从保存的演示结构生成 PPTX、讲稿和预览。
