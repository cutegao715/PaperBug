# 云端对话与本地工作空间第一阶段

本阶段的独立云端 API 位于 `backend/`，可独立安装的本地工作空间位于 `frontend/`。旧版 `paperagent.server` 与原研究空间继续单独运行，不应把旧版无身份隔离 API 暴露到公网。旧 `paperagent.cloud.app` 源码入口作为兼容转发，实际实现位于后台工程。

## 本机启动

在项目根目录使用两个终端：

```powershell
python -m pip install ./backend
paperagent-cloud
```

```powershell
python -m pip install ./frontend
paperagent-desktop
```

打开 `http://127.0.0.1:8766`，注册或登录，创建研究空间并发送消息。模型使用现有 `.env` 或环境变量中的 `PAPERAGENT_LLM_BASE_URL`、`PAPERAGENT_LLM_API_KEY`、`PAPERAGENT_LLM_MODEL` 和可选 `PAPERAGENT_LLM_PROTOCOL`。消息和最近 20 条已完成记录会发往所配置的模型服务；无模型配置时显示失败，可以重试。选择本地文件目前只显示文件名，不读取或上传文件。

云端数据库默认是启动目录下 `cloud-data/cloud.sqlite3`，通过 `PAPERAGENT_CLOUD_DB` 指定服务端路径；启动目录改变时设置为原数据库的绝对路径，可继续使用原有账号及对话。它存储账号、密码派生值、会话令牌摘要、空间和对话。前端会话令牌保存在当前浏览器会话中，退出时撤销。指定前端来源可用 `PAPERAGENT_CLOUD_ORIGINS`，逗号分隔。

## 范围与部署限制

已实现注册、登录、退出、个人研究空间、空间内持久对话、用户作用域校验、请求幂等与同空间单次回复互斥。模型调用复用现有客户端，科研回复由模型生成；尚未接入原有多步决策循环、Skill、文件操作或本地执行器。

当前使用单实例 SQLite 和同步模型请求，是本机开发及受控试点原型，不具备生产云服务所需的身份验证防滥用、密码重置、持久 Worker、分布式并发、设备凭据、备份、存储额度和审计。不要直接开放注册到公网。远程部署需要 HTTPS、受控网络、明确允许的前端来源、加密存储、独立生产数据库及安全评估；前端只允许 HTTPS 远程地址。当前启动时将未完成请求标为失败供用户重试，不能多实例共享数据库。

请求失败后，同一页面再次发送相同文本使用原请求标识；服务端保留失败状态并允许重试。页面刷新后可见失败记录，但恢复已提交的请求标识和流式进度属于后续工作。对话明文存储于数据库；用户删除与保留期限功能尚未实现，不应使用真实敏感材料进行试点。

科研 Agent 接入正在实施：云端有隔离任务、设备注册与撤销、读取操作、五分钟领取租约及幂等回传。本地提供所选 PDF、TXT、Markdown 预览、授权和持久操作记录；原型界面可在确认后执行受限的“请求读取 → 回传 → 继续判断”流程。用户确认会把选中文件的一份副本保存在本机 `~/.paperagent/local.sqlite3`（可设置 `PAPERAGENT_LOCAL_DB`），并将预览中的提取文本发送云端；原文件路径不发送。

后台已装入原有 35 项 Skill 定义及资源、原 SkillLoader 和 10 项 Workflow 契约；用户可选择方法和流程，或让任务自动筛选方法。云端可通过 `read_context` 读取已选 Skill 声明的文本资源，并在后续决策中使用。流程契约提供方法指导，不代表完整 Workflow 状态机已经迁移。

这一流程已接入原 `LLMAgent`、动作模型和科研提示，并在云端按当前可用工具限制动作：支持 `read_context`（选中 Skill 的资源）、`read_pdf`、`chat_reply` 和 `finish`。**原 `DecisionLoop`、完整工具执行器和 Workflow 状态机尚未迁移**；其他动作返回错误。实际执行不是原有全部能力。本机可读取 DOCX，但还没有写回、差异确认和导出。界面刷新后尚不能自动恢复进行中的任务，设备凭证仅保存在浏览器会话；任务步骤和本地队列记录落盘，但完整的自动续接、授权撤销界面和提交结果前的再次校验尚未完成。请仅用测试材料验证，不作为完整科研 Agent 或生产版本使用。
