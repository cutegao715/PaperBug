# 云端科研 Agent 与本地工作空间实施计划

> **For agentic workers:** Use `executing-plans` task by task, with test-driven development and verification-before-completion.

**Goal:** 按改造手册实现云端个人科研 Agent 与独立安装的本地科研工作空间。

**Architecture:** `backend/` 保存账号、授权、科研决策、任务状态和主动服务；`frontend/` 承载界面及受控本机执行。通过认证的 FastAPI 契约交换不透明文件引用和结果，不传本地绝对路径。云端用户隔离、额度和数据生命周期由服务端执行。

**Tech Stack:** Python 3.10+、FastAPI、SQLite 原型、Pydantic、现有 Agent 和工具、HTML/JS。

**Spec:** `docs/personal_research_assistant_cloud_local_transformation_plan_v1.md`。

## 全局约束

- 逐项保留原有科研动作的含义；没有迁移的动作返回明确不可用，不让模型宣称已执行。
- 云端和本机独立安装；不自动上传原文，不接受云端任意命令和路径。
- 多用户强制校验；原始文件不覆盖；任务、操作和费用重复请求不得重复生效。
- 当前是单实例 SQLite 原型；生产支付、部署和外部账号接入必须建立真实配置和验证，未接入时明确显示。
- 当前工作区不是 Git 仓库；保留原文件和回退记录，不执行 Git 提交。

## 阶段与验收依赖

| 阶段 | 工作 | 验收门槛 |
| --- | --- | --- |
| A | 设备绑定、授权、队列和可恢复回传 | 两账号两设备隔离，撤权和重启可验证 |
| B | 原科研 Agent 动作适配、持久任务与观察 | 多步任务读取本地材料、继续推理并交付 |
| C | 本地稿件编辑、版本对比及导出 | 导师意见改方法章节，用户采纳另存 DOCX，原稿未被覆盖 |
| D | Skill、Workflow、记忆和迁移 | 写作、评审、申请各一个可复核案例；历史导入不越权 |
| E | A1/A2/A3 与桌面提醒 | 本机关闭仍监测，重连补取，撤销后停止 |
| F | 账本、配额、身份与模型策略 | 并发预留不超额、失败可补偿、供应商切换受授权 |
| G | 真实支付、安装、运维与可选扩展 | 真实外部依赖经独立集成验证；上线前完成安全与恢复验收 |

F 的观察账本可提前开发；实际收费在 E 的闭环和成本验证完成之后。G 的外部支付与云部署依赖真实供应商、凭证和发布决策；在缺失时完成本地可测试实现及接入说明，并如实标记未上线。

两个 Python 工程已拆分，账号、空间、对话和用户隔离测试可用；云端有任务与读取操作记录，本地可提取 PDF/TXT/Markdown。设备绑定、文件授权、Agent 接续和用户界面尚未连接。旧 Agent 的 `DecisionLoop` 依赖本地 `Workspace` 和同步执行器，不能整体直接搬到云端。
