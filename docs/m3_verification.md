## 配置与边界

在生命周期面板的“云同步设置与阶段历史”里进入“关注与通知同步范围”。分别选择项目意图、全局个人意图、转发现有及后续本机通知；必须明确确认，且仍受总 cloud_sync 开关约束。撤销单项授权先本地生效，控制请求失败也不会继续该项上传。绑定凭据继续使用 M2 的配置，当前实现不修改用户凭据或自动开启同步。

通知进入云端持久收件箱，`GET /api/v1/notifications/relayed?device_id=...` 需用户令牌与设备凭据；可指定目标设备，跨用户目标被拒绝。并非发送邮件、移动推送或系统通知。本地通知始终独立可读。

新意图修改/删除入口为 PATCH/DELETE `/api/v1/standing-intents/{intent_id}`（旧 `/api` 兼容窗口保持）。范围调整产生新身份；客户端应使用返回的新 intent_id。纳秒更新时间仅用于配置 LWW，不意味着分布式时钟能识别真实业务因果；同时间以版本、来源、规范化内容稳定决胜。

本地 outbox 在未授权时也只是内部本地持久化，不发出网络请求。服务器拒绝或网络故障一次失败后结束该轮并退避，重试不会阻塞 notify 返回。后台同步仍有有界网络等待；角色权限覆盖应用代码调用入口，不将 Python 扩展当作操作系统沙箱。

Ruling: 意图跨范围编辑保留旧墓碑并生成新身份 — 维持项目隔离和删除语义 — 返回的 intent_id 会变化，外部调用方须更新引用。
