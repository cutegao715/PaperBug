# 从证据卡到综合矩阵
按需调用 literature_matrix，可按 ref_ids 或 theme 筛选并分页。它读取现有引用与证据，不建立第二份综述数据库。无证据卡的引用显示 metadata_only；这不证明未读，也不能声称已完成全文核验。
比较各研究的方法、对象、主要发现、局限与适用边界，区分支持、反驳和背景关系。关系和 finding 是分析标注，source_freshness 只比较文件版本，均不是科学真伪认证。
主题综合要说明证据共识、差异、可能解释及材料不能支持的结论。出现频率不等于证据权重。缺口来自现有证据边界，不因缺少某方法就断言该方法必需。
需要扩大检索或重读原文时，保存可恢复的检索方向与未解决问题到既有对话上下文；作者采纳的研究定位保留在原有论证记录。
