# 文献库组织与阅读深度
依据当前请求选择深度：一段研究背景可做轻量主题综合；需要可追溯综述时再记录范围、检索、筛选和证据覆盖。不为局部工作强制建立完整协议，不将综述阶段变成新的用户 Task 板块。
复用 references 与 evidence：文献身份只保存在引用库；原文片段、页码／章节、支持命题保存在证据卡。研究方法、对象、发现、局限、主题和支持／反驳关系可按需标注。摘要阅读不能标作全文阅读；来源更新后重新核对受影响证据。
需要完整检索时，在已有资料或对话计划中记录问题、来源库、检索式、日期、纳排标准和筛选理由。初始种子、前向／后向引文追踪和新近检索按问题组合，不强制论文数量或引用次数阈值。
保留实际原始来源，不以摘要代替原文证据。不把可下载等同于可重新分发；上传或打包原始论文前依据实际授权处理。本地材料缺失时允许有限范围综合并披露边界。
