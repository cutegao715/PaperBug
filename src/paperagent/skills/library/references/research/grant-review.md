# 项目申请专项评审
区分科学论证审阅、可读性审阅与依据具体指南的评审。不要求先评完整申请书，选题、目标、研究方案、预算说明或某一节都可独立评审。
科学审阅检查问题—目标—方法—证据—交付是否匹配、创新主张边界、可行性、风险与替代方案。适用的资格、预算、期限和验收条件来自当前项目指南；不要推测申请人资历、已有成果或条件。
首次评审尽量只用当前申请稿、必要事实与适用要求，减少写作辩护影响。返修复核可补充原意见和修改记录。当前单 Agent 运行时不保证独立新上下文或多评委模拟，不伪称已执行独立评审团。
保存报告复用 save_paper_review / PaperReviews，review_kind=grant，review_mode=scientific/readability/criteria。报告绑定当前草稿哈希；发现包含定位、问题、依据、影响及建议。复核、作者采纳与事实核验分开，不另建申请评审台账。
具体标准模式必须提供 review_profile 和非 user_note 的来源；结构校验不代表标准本身已被确认官方有效。未知或不适用条目标为 unavailable 或 outside_scope，不预测中标。
