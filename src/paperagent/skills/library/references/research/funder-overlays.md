# 按资助机构与类型选择资源
按实际指南识别机构、资助类别、年度、申请轮次与交付要求；不能仅凭某个标题就认定 NIH、NSF 或 NSFC。未知时可以先做通用论证审阅，只在标准歧义会改变关键判断时澄清。
NSFC 可关注科学问题、研究目标与内容、技术路线、创新依据、研究基础和条件；NIH、NSF、职业发展或转化类资助各自有不同要求。以上只是待核对维度，不是官方完整评分表。
机构规则、页数、预算、评分尺度和资格会变，使用当前指南资料而非此文件的静态数字。原 research-skills 主要覆盖 NIH/NSF；未直接复制为中国项目的评审标准。
将适用条目与来源定位关联，在报告标明依据、年度和适用范围。评分只在用户确实需要且有适用尺度时提供，并说明主观性质；绝不转换成获批概率。重投评审结合原意见、实际修改和新标准，不机械先降档或重写全部内容。
