# 图表检查与修订
检查可独立请求，不必须先绘图。优先读取明确版本的 SVG 或已有图表记录，使用 figure_quality_check，按需提供 expected_text、min_font_size、min_width、min_height。
工具检查 XML、活动／外部内容、明确文字、直接声明字号和基本尺寸；继承样式或 CSS 字号可能不可解析，几何重叠、裁切与视觉质量目前仍需渲染后检查。SVG 用户单位不能直接当最终印刷字号。通过只表示实际运行的确定性检查无错误。
报告分开列出 errors、warnings、已执行 checks、unavailable 和视觉判断，关联输出 sha256。检查无法运行时不可写成通过。
有工具可渲染时，按最终显示或印刷尺寸检查文字、配色、层次、坐标、图例、面板和图注。存在真实数据的图还要核对源数据及命题边界。
修订选择高影响问题，复查受影响部分；轮次和预算依据本次需求约束，避免无限自我打磨或固定多个 Agent、固定候选数量。
