# 科研图表规划与样式
先确认当前图要支持的命题、真实数据或结构、受众与目标载体。数据关系用可复现绘图，方法或机制示意用可编辑矢量结构；AI 插图可辅助概念表达，但不能捏造测量数据、数值或图中证据。
跨图一致时可用 figure_style 读取／设置空间默认配色、字体和字号，单图允许覆盖。配置不是必须前置步骤；不将模板预设当作目标期刊正式要求。
chart_generate 支持基本柱图、折线、散点图，接受真实数据并输出 SVG 与数据哈希；diagram_generate 目前输出 Mermaid 结构，不声称已渲染。其他复杂图形应报告工具边界，保留源数据和制作代码，不冒充已执行。
图注说明变量、单位、样本、比较条件、不确定性含义和来源，以实际信息为准。saved FigureArtifact、source_data、图文件和内容哈希继续作为共同上下文，不另建图表记忆。
