# 证据与主张的边界
复用空间资料、引用记录、论文论证记录和已有来源定位。无需建立另一套 source_manifest、claims.csv 或稿件记忆。

承重主张核对原文与实际结果：研究对象、设计、指标、比较条件、方向、效应量和不确定性是否支持当前措辞。设计完整、报告合规和结论有效是不同判断。相关性不能直接支持因果；模拟、代理指标或特定数据上的结果须保留边界。

区分作者提供、原始资料、检索摘要、模型推断和未核实信息。检索片段与生成摘要不能代替支持主张的原始证据。文献存在、元数据匹配、原文支持和发表状态分别记录，不能相互替代。

沿用已有 source key、文件版本、章节或页码；来源变化或跨阶段继续写作时，复核受影响论证。新判断作为候选，作者采纳和科学核验保持可区分。缺材料时缩小结论并说明缺口，不自动阻断所有局部工作。
