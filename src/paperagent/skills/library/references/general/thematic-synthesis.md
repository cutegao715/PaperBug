# 主题综合与研究情境比较
先按研究问题及现有材料选择比较维度，如机制、方法、数据、测量、情境或证据分歧。主题数量随问题而定，不以作者名单拼接章节。

每个主题说明已知发现、支持来源、差异及可能解释、尚不能回答的问题。矛盾应核对样本、方法、指标、时间和情境，不能直接归因于某国家或群体。

只有国内外或地区差异与问题相关且有可比证据时才采用该视角；不要求双边文献配额、固定批评次数或强行制造对比。文献不足可做有边界的初步综合，并明确检索范围。

研究缺口由已有证据的解释范围推出，不预设所有研究都需要质性方法、机制模型或统一理论。引用格式服从目标交付要求。承重比较需要可追溯定位；核查引文时按需读取 citation_verification。
