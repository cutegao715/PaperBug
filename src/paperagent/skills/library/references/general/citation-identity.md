# 引用身份、支持关系与发表状态
根据请求确定核查范围，不把单句润色扩展成全库审计。

分别检查：
- 身份：题名、作者、年份、刊会、卷期页码或文章号与权威记录是否匹配。
- 标识：DOI 等是否登记，是否指向同一作品；有效 DOI 不等于当前条目正确，没有 DOI 也不等于伪造。
- 支持：读取可获得原文，定位当前命题的章节、页码或结果；不能以元数据或摘要检索成功声称全文支持。
- 状态：需要时核对出版方勘误、撤稿、版本变化，并记录查询日期。

优先使用原出版记录、注册机构和作者提供原文；互相冲突时保留差异，不猜测。超时、429、权限不足与未检索到均不能直接判定文献虚构，标为待核实并说明尝试范围。

复用已有 references/evidence/materials 与来源 key。修正文献身份后检查正文指向和论证影响。只宣称实际完成的检查；不得编造标识、引文或定位。
