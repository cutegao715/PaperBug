# 机器学习研究的评估与报告
仅当实际研究包含训练、预测或模型比较时使用，不将所有计算机科学论文都当作 ML 论文。通用实验设计、论证和语言方法仍复用对应 Skill。

检查任务定义、数据来源与许可、样本单位、划分方式、预处理、基线、公平比较、指标和实际计算预算。特征选择、标准化等拟合步骤应限于训练数据或交叉验证训练折，避免信息泄漏；存在同人、同组或时间依赖时选择适当的组划分或时间划分。

区分验证集上的选择与测试集上的最终评估，不把反复调参后的测试表现当作独立泛化证据。按实际实验检查随机性、重复、置信区间或其他适用不确定性报告，不能虚构运行次数。

主张限定于评估的数据、指标、场景和比较条件。复现信息覆盖模型配置、软件环境、超参数与代码可用性；缺项如实报告，不靠清单完成度判定科学质量。
