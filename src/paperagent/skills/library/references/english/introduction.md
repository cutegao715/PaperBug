# 引言与研究背景
本资源服务于期刊、会议论文的章节功能，通用论证方法见 academic_writing。按当前文本和研究类型选择需要的部分，不规定段数、长度或写作先后。

让读者理解研究问题为何值得关注、相关工作已经解决什么、当前问题具体卡在哪里，以及本文如何回答。贡献应与问题、方法和实际结果对应；目标、假设和研究问题可以是单个、并列或层级关系。

缺口可以是经验、方法、解释或应用边界；必须可由文献和研究情境支持，不把“首次”“无人研究”作为默认卖点。综述型、理论型、质性与方法论文不强套同一 IMRAD 模板。

只在有助定位且证据充分时比较国内外情境；较完整的主题综合读 evidence_synthesis，不用固定地区文献数量替代覆盖判断。是否需要更新文献取决于主张的时效性，不统一规定年份门槛。

与摘要、方法、结果、结论和已确认术语交叉核对，避免引言承诺超出论文实际完成内容。范围仅为局部修改时保留工作范围。
