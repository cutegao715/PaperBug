# Figures, tables, equations and supporting material

Apply only when the requested change involves displays or their dependencies. Use existing material and current output; do not fabricate figure values.

Allocate information by reader function: caption/notes explain what is shown and how to read it; body states the supported finding and comparison; Methods or supplement carries extended procedures. Avoid duplication while retaining definitions, denominators, uncertainty and exclusion conditions needed to interpret a display independently.

Check labels, units, panel mapping, uncertainty definitions, sample sizes and callouts against the actual figure/table. Distinguish an SD, SE, confidence interval or credible interval only from evidence, never the appearance of error bars. Check equations, symbol definitions and units where affected.

Develop supporting material alongside the relevant methods/results when useful. Keep supplementary figures, methods, source files and citations aligned with the main text. Which files and references are allowed depends on the venue and stage; do not import another journal's rules.

Use exact active file versions. When a figure or result changes, revisit affected captions, prose, abstract and supplement. Versioned source pointers do not prove visual readability.

Use appropriate document/LaTeX/PDF tooling to inspect final-size layout, clipping, fonts, table breaks and cross-references. If rendering or the relevant file is unavailable, report the check as unperformed. This guide does not itself compile LaTeX or render Word.
