# Manuscript context and continuity

The research workspace is the owner of manuscript knowledge. Use read_context(kind=manuscript) for profile and records, or key=<record_id> for a record's current state and history. The preview is bounded; use the full registry to discover omitted records. Existing messages, conversation checkpoints, memories, imported materials, evidence cards and draft versions remain authoritative for their respective purposes. Do not initialize the external skill's manuscript_state template or duplicate the conversation plan.

Read relevant confirmed records before sustained writing. Term records distinguish preferred wording, definition, allowed variants and discouraged variants. Argument records connect a question to method, evidence, result, interpretation, boundary and contribution; partial records are valid during planning. Venue rules distinguish official requirements, observed examples and preferences, tied to the target profile and source.

Use record_manuscript_context only for reusable paper-specific proposals. Agent suggestions remain proposed; they cannot overwrite confirmed terms or claims. User adoption records a decision, not scientific truth. Source evidence can still contradict an adopted claim. Keep unresolved conflicts visible and propose corrections with their basis.

A new record should cite existing draft/material/evidence identifiers or an exact user statement. Sources use existing workspace versions; never infer author names, sample sizes or findings from a filename or old draft. Link related records when a term or argument depends on a prior decision so later revision becomes visible.

On resumption, read the current request, current draft version and relevant paper records. A changed linked record, source or venue profile is a reason to re-evaluate affected content. Do not replay prior edits or reload all guide chapters. The shared Skill provides methods and never stores this paper's private facts.

For a one-off paragraph edit, use supplied context without demanding a full profile, glossary or argument map. Missing surrounding text limits what can be claimed about flow but does not prevent a useful local edit.
