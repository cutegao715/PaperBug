# Scoped review and revision

Choose the depth using four axes: requested action, textual unit, change impact and available verification sources. A whole-file punctuation pass is not a scientific review; a one-line change to the main result may affect multiple artifacts.

For an independent reviewer-style assessment, discover the shared paper_review Skill and its relevant internal resources. It can be used directly without drafting, revision or a Workflow. For supplied reviewer comments requiring a reply, use reviewer_response as appropriate.

For substantive review, inspect relevant argument/structure, evidence/scope, English prose and delivery consistency. These are dimensions, not a required tool-call sequence. Return located findings, why they matter, supporting evidence and a repair or unresolved question. Label uncertain findings; avoid inventing defects to fill a checklist.

Classify changes to decide affected dependencies:

- Research question or contribution: revisit the affected evidence chain and summaries.
- Methods, numerical results, figures or limitations: revisit linked methods, results, displays, interpretation and summaries.
- Author/funding/declaration metadata: revisit artifacts carrying those fields.
- Grammar or typography: preserve local meaning and relevant layout.

This does not authorize editing every dependent file. Identify affected files and act within the user's scope.

For reviewer response work, use the shared reviewer_response capability where relevant. Preserve original comments and distinguish strategy, proposed response and verified completed changes. Give each substantive concern an answer with evidence and a real change locator, or an evidence-backed reason for no change. A generated reply is not proof an analysis was run.

Record review scope as checked, not applicable, outside scope or unavailable. Pattern scans, citation existence and field completeness must not be described as semantic peer review. A whole-paper readiness claim requires the applicable actual source and artifact checks; a local draft can still be delivered with clear limits.

Check the exact delivered candidate, using content/version identifiers where available. Changes to evidence, terminology or a venue requirement can invalidate a prior result even when the sentence is unchanged. Recheck affected dimensions without forcing an unrelated whole-paper audit.
