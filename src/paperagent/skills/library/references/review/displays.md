# Displays, symbols and derived quantities

Use for substantive equations, indexed variables, normalized or aggregated values, composite measures, or cross-file notation. A simple explicit table does not require an exhaustive symbol ledger.

For material symbols, track meaning, unit/scale, indices, defining location and affected text, equations, captions, tables and supplements. Distinguish parameters from estimates, source variables from transformed quantities, and group/time/scenario indices. Missing definitions are questions to resolve, not permission to invent notation.

Trace data/model output → transformation → aggregation/normalization → displayed quantity → textual claim. Inspect relevant denominator, baseline, reference group, weighting, exclusions, zero/missing handling and uncertainty definition. A shaded band might represent several different quantities; its visual appearance is not evidence of a particular one.

Distinguish notation conflict, definition gap, provenance gap, display–claim mismatch and cross-artifact regression. A cosmetic preference is not a blocker unless it materially affects interpretation or reproducibility.

Inspect original-resolution displays or rendered artifacts when a claim depends on visual details. Text extraction alone does not establish plotted accuracy or layout quality. Mark the unavailable checks explicitly and preserve legitimate no-change outcomes.
