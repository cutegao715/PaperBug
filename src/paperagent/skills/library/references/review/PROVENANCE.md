# Provenance

The PaperAgent review resources adapt and condense the user-supplied paper-review
Skill and its neutral domain/method resources, with relevant manuscript-integrity
concepts from academic-writing-skills, Copyright (c) 2026 Wenyu Chiou, MIT license.
The complete license is reproduced in LICENSE.txt in this directory.

Source: skills包/academic-writing-skills-main/skills/paper-review and the adjacent
academic-writing-skills package. Adapted resources include overlay-contract,
round-calibration, review-checklist-and-cases, display-notation-provenance,
quantitative-psychometrics-sem, ai-llm-computational, water-cnhs-uncertainty and
flood-hydrodynamics-catastrophe.

Personal reviewer overlays, named project precedents, fixed pass requirements,
external state templates and audit executables are not imported. Domain cues
select optional guidance; they neither certify a manuscript nor impose an ordered
workflow. Original user-supplied files remain unchanged.
